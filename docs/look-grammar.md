> - **적용 범위**: 모든 시각 작업의 판정 기준. 룩을 바꾸는 PR은 이 문서와의 정합을 리뷰 요건으로 한다.

## 1. 장르 선언

cheoma의 장르는 카툰도, 로우폴리 쇼케이스도, 리얼리스틱도 아니다.

> **"빛과 대기로 통합된 회화적(painterly) 스타일라이제이션"**
> — 형태는 절제하고, 시네마틱한 빛과 공기가 화면을 하나의 그림으로 묶는다.

같은 원리의 선례: 지브리 배경화(단순한 형태 + 정교한 빛), 겸재 진경산수(능선 겹침·운무 절단·여백).
수묵 모드는 이 스펙트럼의 명시적 "회화 끝단"이다.

### 왜 이 장르인가 (비용 대비 효과)

| 선택지 | 판정 | 이유 |
| --- | --- | --- |
| 리얼리스틱 | ✗ | 절차 생성 에셋의 디테일 밀도로는 리얼 문턱을 못 넘고, 넘으려면 에셋 단위 비용이 폭발한다. |
| 풀 카툰(외곽선·플랫 컬러) | ✗ | "학습 자료 수준 고증"(목표 G4)의 재질·색 충실도와 충돌한다. |
| **회화적 스타일라이제이션** | ✓ | **빛·대기는 포스트 체인 + 셰이더 패치 몇 개로 전 씬에 적용되는 지렛대다.** 에셋을 하나하나 올리는 것보다 압도적으로 싸고, 이미 구현돼 있다(post.js·rim.js·fog·DoF). 로우폴리 기하는 빛이 살아 있으면 "의도된 절제"로 읽히고, 빛이 죽으면 "값싼 미완성"으로 전락한다 — 골든 A/B가 증거. |

## 2. 세 가지 통합 원칙

1. **빛과 대기가 통합자다.** 역광 림 + bloom 헤이즈 + DoF + fog가 화면 전체를 한 겹의 대기로 잇는다.
   어떤 오브젝트도 대기 밖에 있으면 안 된다(스카이돔 포함). 새 요소를 추가할 때의 첫 질문은
   "이것이 빛을 받는가"이지 "디테일이 충분한가"가 아니다.
2. **실루엣 우선 형태 언어.** 처마곡(앱 이름의 그것)이 프레임의 주선(主線)이다. 디테일 투자는
   실루엣과 큰 면(지붕선·용마루·담장 상단·능선)에 우선하고, 채움 디테일(마당 소품 등)은 절제한다.
   한 프레임 안에서 요소 간 디테일 밀도 계약을 일관되게 — 기와는 골까지 파면서 관목이 8면체면 장르가 깨진다.
3. **채도 규율.** 웜(주홍·금빛)은 하이라이트·림·발광에만. 그림자와 미드톤은 중성을 유지한다.
   높은 채도 포인트(등불·창불·단청)는 화면당 소수의 의도된 악센트다 — 대기와 무관하게 튀는 순간
   카툰 악센트가 되어 장르를 오염시킨다. 뇌록·주홍·수목 녹·하늘은 서로 구분되는 색상을 유지하되
   하나의 대기 안에서 만난다(단일 주황 워시 금지).

## 3. 요소별 규율

| 요소 | 규율 |
| --- | --- |
| 하늘 | 반드시 대기 원근에 참여한다. 지평 밴드는 fog색으로 수렴하고, 지형–하늘 경계에 하드컷이 보이면 실패. 하늘 채도가 지형을 누르면 안 된다. |
| 지형·숲 | 로우폴리 허용 — 단 패싯 스케일을 화면 안에서 균일하게. 원경은 대기(안개 층·능선 겹침)로 소실시킨다. 세계의 "끝"이 프레임에 보이면 실패(worldedge 연출로 마감, 지형 확장 금지). |
| 건물 | 실루엣(지붕곡·용마루)과 근접 부재(공포·창호·기단)가 디테일 투자처 — 이것이 G4(고증) 담당. 재질은 단순하되 빛 반응(림·스펙큘러)은 정확하게. |
| 입자·생명감 | 물리 크기 계약 유지 + 역광에서 발광(모트·연기·낙엽은 빛을 보여주는 장치다). 화면은 절대 완전 정지하지 않되 모든 모션은 미세 스케일. |
| 물·야간 발광 | 발광은 광원의 물리적 근거가 있어야 한다(달빛 스펙큘러·한지 투과). emissive 남용 금지. |
| 수묵 모드 | 농담(濃淡) 대비와 여백이 생명 — 균질한 회색은 실패. 이 모드가 G3(동양적 미감)의 기준기다. |

## 4. 판정 리트머스 (모든 시각 게이트에 적용)

- **"이 프레임이 그림으로 읽히는가, 게임 스크린샷으로 읽히는가?"** — 그림이어야 한다.
- **리트윗 테스트**: 이 컷을 three.js 커뮤니티에 올렸을 때 "어떻게 만들었지?"가 나오는가.
- 회귀 테스트와 별개로, 장르 정합 위반(플랫 하늘, 언릿 덩어리, 대기 밖 채도 악센트, 디테일 계약 붕괴)은
  골든과 같더라도 미달이다.

## 5. 금지 목록

- 외곽선 토온 셰이딩의 전역 적용(수묵 모드 밖).
- 리얼 텍스처 추가로 장르 문제를 해결하려는 시도(비용 폭발 + 장르 혼선 가중).
- 빛 반응 없는 디테일 추가("어두운 데서 안 보이는 조각").
- 대기 규율 밖의 채도 악센트 남발.
- 성능을 이유로 통합자(림·헤이즈·fog·DoF)를 끄는 것 — 통합자는 이 앱의 본체다. 비용은 다른 곳에서 줄인다.

## 6. 투자 우선순위 (비용 대비 효과 내림차순)

1. **포스트·림·대기 튜닝** — 거의 0 비용으로 전 씬의 장르를 결정한다. (현재 Phase 1)
2. **채도 규율 정렬** — 팔레트·발광 강도 조정 수준. (창불·풀 틴트·단청 노출)
3. **디테일 계약 정렬** — 튀는 소수 요소만 선별 보정(예: 8면체 관목). 전면 리모델링 금지.
4. **에셋 신규 디테일** — 실루엣·근접 부재에 한해, 최후에.
